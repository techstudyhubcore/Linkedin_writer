PROCESSING RULE
======================================================================

Never save information directly.

Always answer:

1.

What is the main idea?

2.

Why does it matter?

3.

How does it connect to my Knowledge Map?

4.

Can I explain it simply?

5.

Can I apply it?

6.

Can I teach it?

If not...

I probably don't understand it yet.
